## 🚀 Quick Start

### 1. Installation
```bash
pip install -r requirements.txt
```

### 2. Configuration
Copy and configure environment variables:
```bash
cp src/config/.env.example .env
# Edit .env with your API keys and credentials
```

Required credentials:
- `GEMINI_API_KEY`: Google Gemini API key
- `INSTAGRAM_USERNAME`: Instagram account username
- `INSTAGRAM_PASSWORD`: Instagram account password
- `OPENAI_API_KEY`: For embeddings (optional)

### 3. Run the System

#### Daily Content Flow
```bash
python src/orchestrator/main.py
```

#### Start Scheduler
```bash
python src/orchestrator/scheduler.py
```

#### Launch Dashboard
```bash
python src/monitoring/dashboard.py
# Access at http://localhost:5000
```

## 🛠️ Troubleshooting

### Common Issues
1. **Instagram Login Fails**: Check credentials, enable 2FA if required
2. **Content Scraping Errors**: Verify internet connection, check site availability
3. **Vector DB Issues**: Ensure ChromaDB permissions, check disk space
4. **Gemini API Errors**: Verify API key, check quota limits
5. **Image Generation Fails**: Check PIL dependencies, verify file permissions
